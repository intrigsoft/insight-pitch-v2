# Security policy

Insight Pitch holds people's accounts, votes and comments on public decisions, so we take security reports
seriously.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub instead:
**Security → Report a vulnerability** on this repository
([direct link](https://github.com/intrigsoft/insight-pitch-v2/security/advisories/new)).

Include what you found, how to reproduce it, and what someone could do with it. We'll acknowledge the report within
a few days, keep you updated while we fix it, and credit you when it's disclosed unless you'd rather stay anonymous.

## Scope

In scope: this repository's code. Please test against your own local copy, not against hosted environments.

Known and intended: the sample accounts share a public password (see the README). That's not a vulnerability by
itself, but anything that lets an account do more than its role allows is.

## Supported versions

Only the latest commit on `main` is supported.
